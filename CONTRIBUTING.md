# Contributing to FloatNote

Thank you for helping improve FloatNote.

1. Search existing issues before opening a new one.
2. Keep changes focused and preserve the portable, low-resource design.
3. Build with `/W4` and run `./build.ps1 -Test` before submitting a pull request.
4. Describe the Windows version, architecture, display scale, and whether transparency effects were enabled for UI or compatibility bugs.
5. Do not commit personal `data`, build output, screenshots containing private notes, or generated binaries.

For visual changes, include a before/after screenshot and explain which Windows mode was used: standard transparency, rounded glass, High Contrast, Energy Saver, or Remote Desktop.
