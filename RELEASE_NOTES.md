# FloatNote 1.0.0

FloatNote is a tiny, portable desktop memo for Windows. This first open-source release includes English and Simplified Chinese interfaces, local atomic saving, themes, standard transparency, rounded glass on supported Windows 11 systems, mouse click-through, tray controls, and startup support.

Choose `windows-x64` for most PCs, `windows-x86` for 32-bit Windows 10, or `windows-arm64` for Windows 11 ARM devices. Extract the archive to a writable folder before running it. Windows may show a SmartScreen warning because the binaries are not code-signed.

Windows 10 uses standard transparency. Rounded glass is a Windows 11 feature and also falls back when transparency effects are disabled, High Contrast or Energy Saver is active, or the app is running through Remote Desktop.
