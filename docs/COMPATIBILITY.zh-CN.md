# 兼容性说明

FloatNote 的目标范围是 Windows 10 1809（Build 17763）及以上版本。

| 系统 | CPU 构建 | 普通透明 | 圆角毛玻璃 | 说明 |
| --- | --- | --- | --- | --- |
| Windows 11 21H2 及以上 | x64、x86、ARM64 | 支持 | 合成器支持时可用 | 需要开启“设置 → 个性化 → 颜色 → 透明效果”。 |
| Windows 10 1809–22H2 | x64、x86 | 支持 | 仅回退 | 毛玻璃偏好仍会保存，数据迁移到 Windows 11 后可再次生效。 |
| Windows 10 ARM64 | ARM64 | 未进行发布级实测 | 不承诺 | ARM64 发布包由 Windows 11 ARM 的 CI 原生构建与检查。 |
| Windows 8.1 / 8 / 7 | — | 不支持 | 不支持 | 不在支持范围内。 |

## 自动降级

- 高对比度模式使用不透明系统颜色。
- 节能模式暂停毛玻璃。
- 远程桌面使用普通背景。
- Windows 关闭“透明效果”时不启用毛玻璃。
- 圆角毛玻璃所需的 Windows Composition API 不可用时，编辑功能保持正常，并回退到普通透明。

## 显示与输入

- 使用每显示器 DPI；窗口跨屏时跟随缩放。
- 启动或显示器变化后，把保存的窗口范围约束到当前最近的工作区。
- 原生 EDIT 提供输入法组合、Unicode、选择和撤销。没有逐一测试所有具体输入法。
- 全局快捷键可能被其他软件占用；托盘图标和再次运行 FloatNote 始终是恢复入口。

## v1.0.0 的验证范围

- Windows 11 Build 26200、200% 缩放、x64 程序。
- x64 主机上的 x64 与 x86 原生回归。
- 四角圆角毛玻璃、真实背景取色、模糊、鼠标穿透、切回普通透明的合成检查。
- CI 在 Windows Server x64 构建 x64/x86，在原生 Windows 11 ARM runner 构建 ARM64。

CI 证明对应 runner 上可以构建并通过无界面检查，不代表已经覆盖所有 GPU 驱动、OEM 桌面修改、多显示器组合和远程图形栈。
