# 兼容性 — FloatNote 2.0

应用以 Windows 10 1809 及以后的系统 API 为目标；液态玻璃桌面效果主要在 Windows 11 x64 上完成交互与视觉验收。

| 环境 | 预期表现 | 验证范围 |
| --- | --- | --- |
| 支持捕获/合成接口的 Windows 11 | 液态玻璃、系统毛玻璃或纯色 | Windows 11 x64 本机视觉验收；自动检查另列 |
| Windows 10 | 主机背景不可用时采用普通背景，保留基础编辑 | 尚未完成 2.0 的 Windows 10 全面视觉验证 |
| Windows 11 ARM | 提供原生 ARM64 包 | 原生 ARM CI 编译与测试，不等同于完整 GPU 视觉认证 |
| Windows 10 1809 之前 | 不支持 | 不作兼容承诺 |

## 降级与截图

高对比度使用系统颜色；节能、远程桌面、关闭透明效果或合成/捕获 API 不可用时，可能禁用高级材质。原生编辑与恢复控件保留。

液态玻璃在本机捕获显示器背景，并排除便签自身以防画面反馈。该排除也可能让便签不出现在截图或第三方远程串流中；有此需求时，请切换系统毛玻璃。顶部控制和设置窗口独立绘制且不排除捕获，但不保证所有远程软件的表现。应用不会上传或录制屏幕。

## 输入与语言

保留每显示器 DPI、Unicode 原生编辑、选区、输入法和撤销；并非每一种输入法及多屏组合都已单独验证。全局快捷键可能与其他软件冲突，可通过托盘或再次启动程序找回。

新增控制面板、关闭确认和材质参数目前为中文；原有托盘/基础界面保留语言选项。中英文文档不代表新面板已完整英文翻译。

## 发布检查

本地编译 x64/x86，运行原生回归，以及几何、运动、悬浮范围和材质数学检查。GitHub CI 构建三个架构，运行原生及玻璃测试，并验证便携包内的版本、CPU 架构及固定文件清单。这些检查不能覆盖所有显卡驱动、屏幕捕获策略或远程图形环境。
